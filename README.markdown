# kodi-mgmt

A collection of utilities and documentation to help maintain kodi
libraries and instances.

## Goal

To make it easier to work with kodi libraries:

- create, update, and query `.nfo` metadata files
- manage, transcode, and query media files


## Background

I've been using Kodi for a _looong_ time.

Part of its appeal has been the breadth and depth of its customization,
from skins to addons and beyond.  As not just an end user but as a
developer, I've written quite a bit of supporting code and utilities to
enrich the experience, including, but not limited to:

- upstream contributions to improve the default web interface
- published addons, including the world's first Twitter client for the
  original XBox game console
- helper and utility scripts
- one-off, ad-hoc solutions

While some of these have become upstream contributions or independently
distributed packages, a non-trivial amount of this work has remained
closed-source, for one reason or another.


## Overview

This repository aims to become a centralized source for these previously
private and independent projects.

In time, I'll be pulling these works into here to clean up and
consolidate them.

Not only will these enable others to use these contributions, this will
let me work to combine them for a more cohesive experience.

That said, I'm trying to anchor myself to the idea of "not letting
perfect be the enemy of good", so while some of the work may be
immediately beneficial to others, I also plan to include my more niche
and experimental proof-of-concepts.
